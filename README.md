# משפך שאלון: "מחשבון המשרד" לרואי חשבון

משפך Quiz Funnel שמיועד **למשרדי רואי חשבון ויועצי מס**. המסר המרכזי (מאוקטובר 2026): "המשרד שלא שוכח כלום" — לוח דיווחים שמתמלא לבד בתחילת כל חודש לפי התדירות של כל לקוח, משימות ופולואפים מחוברים ללקוח עם תזכורת ב-08:00, קליטת לקוח חדש בקישור, ומעקב שכר טרחה. הוא בנוי מ-3 דפים סטטיים.
העיצוב בהשראת noamgamliel.com: ירוק אמרלד עמוק (#0B2E24), קרם וזהב (#F4B740), ופונטים Rubik + Heebo.

| קובץ | מה זה |
|---|---|
| `index.html` | דף 1: דף הנחיתה, השאלון (5 שאלות, אחת בכל מסך), מסך "מחשב..." וטופס ליד |
| `results.html` | דף 2: התוצאות האישיות, הדליפה הגדולה, הפתרון, הצעת הסנדק (ערימת ערך + בונוסים), אחריות, דחיפות ויומן Calendly |

| `styles.css` | מערכת העיצוב המשותפת |

## הזרימה
1. הגולש עונה על 6 שאלות ← מסך "מחשב" ← טופס (שם וטלפון בלבד).
2. הליד נשלח ל-`leadWebhookUrl` עם כל התשובות והחישוב. התוצאה נשמרת ב-sessionStorage, ומשם עוברים ל-`results.html`.
3. דף התוצאות: ארבעת המספרים ושורת "איך הגענו לזה", ו**מיד אחריהם היומן** (Calendly, עם שם וטלפון ממולאים מראש). דף המכירה הארוך יושב מתחת ליומן, למי שעוד מתלבט. בקביעת פגישה עוברים אוטומטית ל-`thank-you.html`.

## השאלות
1. כמה לקוחות פעילים (המכפיל של כל החישוב)
2. איך יודע מה כל לקוח צריך לדווח החודש (מעקב דיווחים)
3. איסוף החומרים לפני מועד דיווח
4. כמה פעמים בחודש האחרון משהו נפל בין הכיסאות (משימות ופולואפים)
5. שכר טרחה חודשי ממוצע ללקוח (מתרגם זמן לכסף)
6. שכר טרחה פתוח שעבר את מועד התשלום

## לוגיקת החישוב (בדקות לחודש, ב-`compute()` שב-index.html)
| רכיב | נוסחה | כמה נחסך |
|---|---|---|
| מעקב דיווחים | לקוחות × 1/5/10/15 דק' (ש2) | 90% — הלוח מתמלא לבד |
| איסוף חומרים | לקוחות × 4/12/22/35 דק' (ש3) | 60% — חלק נשאר אנושי |
| נפילות | 0/1.5/4/7 תקלות (ש4) × 60 דק' | 80% |

- **שווי שעה** = שכר טרחה חודשי ממוצע (ש5) ÷ `hoursPerClient` (ברירת מחדל 3 שעות ללקוח בחודש).
- **שווי בשנה** = שעות שנחסכות (מעוגל) × שווי שעה (מעוגל) × 12. מעגלים לפני ההכפלה, כדי שהחישוב שמוצג בדף ייצא מדויק — רואה חשבון יבדוק אותו.
- **לקוחות נוספים** = שעות שנחסכות ÷ `hoursPerClient`, כלפי מטה.
- **מועדי דיווח בחודש** = לקוחות × `deadlinesPerClient` (ברירת מחדל 1.5).
- **שכר הטרחה התקוע** (ש6) מוצג בנפרד ולא נכנס לסכום, כדי לא לספור פעמיים.
- **הדליפה הגדולה**: אם ש6 היא 30 אלף ומעלה — "שכר טרחה תקוע". אחרת, הרכיב שחוסך הכי הרבה שעות.
- ההנחות (דקות לכל תשובה, אחוזי החיסכון, `hoursPerClient`, `deadlinesPerClient`) הן הערכות. **לכייל מול עידן** לפני העלייה לאוויר.

## ⚠️ לפני העלייה לאוויר
1. **`config.js`**: `leadWebhookUrl`, `leadFormId`, `leadSecretKey` (מ-LeadSync), `calendlyUrl`, מספר וואטסאפ אמיתי, ו-`calendlyPhoneAnswer` לפי מספר שאלת הטלפון באירוע ב-Calendly. משך האירוע ב-Calendly: 20 דקות בטלפון (כך כתוב בדפים).
2. **ההצעה, ערימת הערך, האחריות והמחסור** הם טקסט ממלא-מקום — נועם ואדר כותבים את ההצעה האמיתית. **ערימת הערך** (סוכן גבייה ₪4,000/חודש, רודף וואטסאפ ₪1,500, מבקש חומרים ₪1,200, דאשבורד ₪800, בונוסים ₪6,100, סה"כ ₪96,100) היא הערכה שלי. צריך לאשר מול המחיר האמיתי.
3. **האחריות המשולשת** היא התחייבות משפטית: (א) 30 יום, המערכת מממנת את עצמה או שלא משלמים, (ב) 90 יום, פי 3 או החזר מלא, (ג) פיצוי על זמן השיחה. לנסח רק מה שבאמת מתחייבים אליו.
4. **המחסור** (`spotsLeft`, `spotsPerMonth`) חייב להיות אמיתי. אם אין מגבלה: `spotsLeft: null`.
5. **הבטחה בטופס:** "הכול גם בוואטסאפ". שליחת התוצאות בוואטסאפ עוד לא בנויה — תיבנה דרך LeadSync ו-n8n (ראו החלטות).
6. **ההמלצה בדף התודה** היא placeholder. להחליף או למחוק את `#testimonial`.
7. מדיניות פרטיות ותנאי שימוש (עדיין לא קיימים) וקישור אליהם מהטופס.
8. פיקסל Meta / GA: הקוד שולח `QuizStart`, `QuizComplete`, `Lead` ו-`Schedule` אם `fbq`/`gtag` מותקנים.

## מבנה הליד שנשלח
הטופס שולח POST עם JSON שטוח (`Content-Type: application/json`). אם הבקשה נכשלת (למשל CORS), הוא שולח שוב את אותו JSON כ-`text/plain` במצב no-cors. גם LeadSync וגם Apps Script יודעים לקרוא את שני הפורמטים. בנוסף נשלח שדה `notes` עם סיכום קריא בעברית, שנכנס להערות הליד ב-LeadSync.

| מפתח | דוגמה | הערה |
|---|---|---|
| `event` / `source` | `quiz_lead` / `yitra0_loss_quiz` | לסינון בתרחיש |
| `submitted_at` | `2026-09-24T07:26:00Z` | ISO |
| `name` / `first_name` | `יוסי לוי` / `יוסי` | `first_name` להודעות וואטסאפ |
| `email` | ריק | הטופס לא אוסף אימייל (רק שם + טלפון). המפתח נשאר כדי שהמיפוי לא יישבר |
| `phone` / `phone_intl` | `050-1234567` / `972501234567` | `phone_intl` לוואטסאפ ול-CRM |
| `q1_answer` … `q6_answer` | טקסט התשובה המלא | `q1_question` … `q6_question` = כותרת השאלה |
| `hours_per_month` | `17` | סך שעות המעקב, החומרים והנפילות |
| `hours_saved_per_month` | `12` | כמה מהן אפשר להחזיר |
| `yearly_value` | `36000` | ₪ לשנה (שווי השעות שחוזרות) |
| `extra_clients` | `4` | כמה לקוחות נוספים הזמן הזה שווה |
| `deadlines_per_month` | `38` | מועדי דיווח בחודש |
| `outstanding_fees` | `20000` | שכר טרחה פתוח (אמצע הטווח) |
| `biggest_leak` / `biggest_leak_label` | `materials` / `איסוף חומרים לדיווח` | `tracking` / `materials` / `slips` / `cashflow` — לפיצול הודעות לפי כאב |
| `utm_source` … `utm_term`, `page_url` | | ייחוס קמפיין |


## העלאה ל-uPress / Elementor
- האתר סטטי: `index.html`, `results.html`, `thank-you.html`, `styles.css`, `config.js` ותיקיית `logo/`. אפשר להעלות כמו שהם לתיקייה בשרת.
- ב-Elementor: כל `<section>` הוא בלוק עצמאי שאפשר להדביק בווידג'ט HTML. את `styles.css` מוסיפים פעם אחת (Custom CSS של האתר), ואת `config.js` והסקריפט שבתחתית כל דף מוסיפים בווידג'ט HTML בסוף העמוד.
- השאלון שומר את התוצאה ב-`sessionStorage`, כך ש-`results.html` חייב להיות באותו דומיין.

## הרצה מקומית

python3 -m http.server 8531

(מריצים מתוך תיקיית הפרויקט ופותחים http://localhost:8531 — לא לפתוח את הקבצים ישירות, כי המעבר לדף התוצאות נשען על sessionStorage באותו דומיין.)

## החלטות (ספטמבר 2026)
- **לידים:** נשלחים ל-**LeadSync** (`receiveWebsiteLead`), לא ל-Make. ב-`config.js` ממלאים `leadWebhookUrl`, `leadFormId` ו-`leadSecretKey` מחיבור הטופס ב-LeadSync. הסקריפט של Google Sheets נשאר כאופציית בדיקה/גיבוי.
- **יומן:** Calendly מחובר ליומן הגוגל. האתר מעביר לדף התודה בעצמו אחרי קביעה (בלי פיצ'ר בתשלום). היומן מוצג **מיד אחרי התוצאות**, והשם והטלפון ממולאים בו מראש — כך הטלפון נכנס לתיאור האירוע, והסנכרון של LeadSync משייך את הפגישה לליד.
- **אחרי השאלון (אוקטובר 2026):** הסוכן G פונה בוואטסאפ רק למי שלא קבע פגישה (שליחת התוצאות + פולואפ), אחרי בדיקת `getLeadStatus` ב-LeadSync. עוד לא בנוי.
- **מסר (אוקטובר 2026):** "המשרד שלא שוכח כלום" — השאלון והדפים מדברים על מעקב דיווחים, חומרים, פולואפים ושכר טרחה, לפי המוצר שנבנה בפועל לעידן. השם "יתרה 0" נשאר.
- **מיתוג:** כפתורי הזהב נשארים (כמו באתר הראשי); הדגשות ה-AI באקווה (#2DD4BF) והצלחה באמרלד (#0E9F6E) לפי הפלטה של NoamG.
- **פונטים:** Heebo ו-Rubik מאוחסנים מקומית ב-`fonts/` (קבצים משתנים, תת-קבוצות עברית ולטינית) ונטענים מ-`fonts.css`, בלי תלות ב-Google Fonts בזמן הטעינה.
- **שליחת לידים עמידה:** בדיקת תשובת השרת, ניסיון שני ללא CORS, ושמירה ב-localStorage עם ניסיון חוזר מדף התוצאות/התודה. שדה מלכודת (`website`) חוסם בוטים פשוטים.

## עדכון גרסה (Cache)
הקישורים ל-`styles.css`, ל-`config.js` ול-`fonts.css` כוללים `?v=4`. אחרי כל שינוי בקבצים האלה, להעלות את המספר (`?v=5` וכן הלאה) בשלושת הדפים, כדי שגולשים לא יקבלו גרסה ישנה מהמטמון.
